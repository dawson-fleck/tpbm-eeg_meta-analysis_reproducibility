# Public release scope

This GitHub folder is the public reproducibility release for the fully locked v2.0 analysis.

Repository contents:

- executable cognition analysis and independent verification code;
- aggregate numerical inputs required to reproduce the models;
- numerical model, sensitivity, influence, diagnostic, and membership outputs;
- dependency and integrity metadata.

Internal project records retained separately:

- project-management links and working-spreadsheet references;
- detailed adjudication and extraction notes;
- source snapshots and local provenance records;
- manuscript figures and the serialized R model cache.

These administrative materials are not used to calculate the published effect sizes or models. The public input files preserve all numerical and categorical variables required by the analysis. The complete project record is retained in the team's controlled storage. The EEG audit is unchanged and remains in the repository's public v1.0 folder.
