# tPBM cognition and EEG reproducibility repository

The current public analysis package is [`tpbm_reproducibility_release_v2.0/`](tpbm_reproducibility_release_v2.0/). It contains the finalized 18-cohort cognitive analysis (N = 680), aggregate inputs, numerical outputs, independent Python verification, and a one-command Windows rerun. Internal project-management materials and source snapshots that are not required to reproduce the analyses are not distributed. The unchanged non-pooled EEG audit remains in the historical v1.0 folder.

The historical [`v1.0`](tpbm_reproducibility_release_v1.0/) snapshot is preserved unchanged because it is the version archived at Zenodo. It contains the superseded 17-cohort analysis and must not be used for the finalized manuscript results.

## Version status

Version `v1.0.0` is archived at [Zenodo](https://doi.org/10.5281/zenodo.23003323). That DOI identifies only the historical 17-cohort snapshot. Version `v2.0.0` was locked on 12 November 2026 after final eligibility adjudication and correction of the Hwang analyzed sample to n = 15 per selected arm. A new Zenodo version DOI has not yet been minted; do not cite the v1.0.0 DOI as if it archived v2.0.0.

The v2.0 package reproduces the finalized cognitive models and independently verifies all 54 effect/variance calculations across three paired-correlation scenarios plus five principal REML/Hartung-Knapp models.
